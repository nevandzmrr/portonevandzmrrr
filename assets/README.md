# Asset folders

Simpan file publik di folder sesuai kategorinya:

- `assets/certificate/` untuk file PDF sertifikat
- `assets/projects/` untuk gambar project

Setelah file di-commit ke repository GitHub, masukkan path relatifnya melalui Admin:

- `assets/certificate/nama-sertifikat.pdf`
- `assets/projects/nama-project-cover.png`

Untuk gallery project, masukkan satu path per baris.
